# SEC-Form-N-PORT-Data-Collection
This repository includes the code used to collect and clean SEC Form N-PORT data for Meredith Kruse's PhD thesis at Rice University. Separate folders in this repository contain the code and RDS files necessary to reproduce the chapter/paper results included in the thesis. The folders are titled according to the paper.

Not all code for feature engineering is included in this repository, and if you have further questions, please reach out to the authors directly.
